Quick start (Windows):
  1. Extract StageWatch_0.2.0_github_ready.zip.
  2. Open a terminal in StageWatch-0.2.0/.
  3. Create/activate a virtual environment.
  4. Install the included wheel:
       py -m pip install --upgrade --force-reinstall .\dist\stagewatch-0.2.0-py3-none-any.whl
  5. Run the complete regression suite:
       py run_all_tests.py
  6. Run the three-pipeline validation:
       py run_three_pipeline_validation.py
  7. Run release metadata checks:
       py scripts\release_preflight.py
